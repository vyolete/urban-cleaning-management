# Admin Components

Components for the admin panel to configure the system.

## Components to implement:

- **ConfigPanel** - Algorithm weight configuration
- **WeightSlider** - Slider for adjusting weights
- **ConfigHistory** - Historical configurations table
- **UserManagement** - User list and management
- **SystemStats** - Dashboard with statistics

## Features

- Real-time weight validation (must sum to 1.0)
- Configuration history
- User role management
- System statistics and metrics
