# Operator Components

Components for the operator dashboard to manage tasks.

## Components to implement:

- **TaskList** - Table/list of tasks with filters
- **TaskCard** - Individual task display
- **TaskMap** - Map showing all tasks with markers
- **TaskDetail** - Detailed task view
- **StateTransitionButtons** - Buttons for state changes
- **TaskFilters** - Filter controls (state, zone)
- **AuditTimeline** - Timeline of state changes

## Features

- Task filtering by state and zone
- Priority-based sorting
- Interactive map with color-coded markers
- State transition validation
- Audit history display
