# Citizen Components

Components specific to the citizen interface for reporting incidents.

## Components to implement:

- **ReportForm** - Form for submitting new reports
- **PhotoUpload** - Photo upload with preview
- **CategorySelect** - Category selection dropdown
- **LocationPicker** - Map-based location picker
- **ReportList** - List of user's submitted reports
- **ReportCard** - Individual report display card

## Features

- Geolocation capture
- Photo upload with validation
- Form validation
- Real-time map preview
