# Ubicación de Documentos del TFM

## 📁 Carpeta de Documentos

Todos los documentos académicos del TFM se encuentran en:

```
tfm-documentos/
```

**⚠️ IMPORTANTE:** Esta carpeta NO está en Git (excluida en .gitignore)

---

## 📚 Contenido

La carpeta `tfm-documentos/` contiene:

- ✅ 10 capítulos del TFM en Markdown
- ✅ Scripts de generación de DOCX
- ✅ Guías y documentación completa
- ✅ Referencias bibliográficas
- ✅ Documentos de planificación

---

## 🚀 Generar Documento DOCX

Para generar el documento final del TFM:

```bash
cd tfm-documentos
./generate-tfm-docx.sh  # macOS/Linux
```

o

```cmd
cd tfm-documentos
generate-tfm-docx.bat  # Windows
```

## 🔒 Seguridad

Los documentos del TFM contienen información académica sensible y no deben:
- Subirse a repositorios públicos
- Compartirse sin autorización
- Modificarse sin respaldo

**Mantener backups en ubicaciones seguras.**
